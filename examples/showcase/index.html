TERMINAL WORKFLOW

Download & Instant Project Initialization

Clone once from GitHub, then use a single terminal command to inject all skills, techniques, and directives into any folder without copy-pasting.

On Windows, clone the repository once, build it, then run .\cwa.cmd init pointing directly to your desired target folder:

# Step 1: Clone from GitHub & build once
git clone https://github.com/Avestroxel/creative-web-architect.git
cd creative-web-architect
pnpm install
pnpm build

# Step 2: Initialize ANY target project folder in 1 command
.\cwa.cmd init "C:\Users\YourName\Desktop\my-new-project"

Using pnpm from inside the cloned repository to initialize any directory on your computer:

# Run cwa init via pnpm targeting your folder
pnpm cwa init "C:\Users\YourName\Desktop\my-new-project"

# Run doctor to verify health
pnpm cwa doctor

On macOS or Linux, use the native executable script ./cwa:

# Step 1: Clone & build
git clone https://github.com/Avestroxel/creative-web-architect.git
cd creative-web-architect
pnpm install && pnpm build

# Step 2: Initialize target directory
./cwa init /path/to/my-new-project

If your terminal is already open inside your target folder:

# Initialize inside current working directory
cwa init .

# Or run directly via Node
node /path/to/creative-web-architect/packages/cli/dist/index.js init .

QUESTIONS & ANSWERS

Frequently Asked Questions

Accurate, transparent answers about what Creative Web Architect is and how it functions.

Creative Web Architect is an open-source AI creative engineering toolkit created by Anas Hashim. It equips compatible AI coding environments with autonomous art direction, 36 modular Agent Skills, motion physics, Liquid Glass components, and performance engineering rules.

Simply clone this repository from GitHub once and run .\cwa.cmd init "C:\Path\To\YourProject" on Windows (or ./cwa init /path/to/project on Mac/Linux). It automatically injects all 36 skills, all 27 learned techniques, and the master AGENTS.md / GEMINI.md directives into that folder in seconds.

By default, Creative Web Architect prohibits cheap neon glows, oversaturated gradients, and childish AI aesthetic defaults. Instead, it enforces mature architectural restraint: matte charcoal surfaces, hairline borders, and pure typographic hierarchy.
