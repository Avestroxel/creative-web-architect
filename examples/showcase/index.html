TERMINAL WORKFLOW

How to Download and Run in Any Folder

Clone once from GitHub, then use a single terminal command to inject all skills, techniques, and directives into any folder without manual copy-pasting.

STEP 01

Download & Build

Clone the repository from GitHub and run the build command once to prepare the toolchain.

git clone ... && pnpm build
STEP 02

Global Link

Link the cwa CLI globally on your system so you can run it from any terminal.

npm link packages/cli
STEP 03

Initialize Target

Run cwa init targeting your project folder to inject all skills and knowledge.

cwa init "C:\Path\To\Project"
STEP 04

Start Building

Open that folder in Antigravity or Cursor and prompt your AI agent to build your website.

Prompt your Agent!

Clone the repository, build it once, and link the cwa command globally so you can use it in any terminal across your entire machine:

# 1. Clone repository from GitHub & build once
git clone https://github.com/Avestroxel/creative-web-architect.git
cd creative-web-architect
pnpm install && pnpm build

# 2. Link CLI globally on your computer (run once)
npm link packages/cli

# 3. Now initialize ANY folder on your computer in 1 second
cwa init "C:\Users\YourName\Desktop\my-new-project"

On Windows, you can also run the bundled .\cwa.cmd executable directly without global linking:

# Step 1: Clone & build
git clone https://github.com/Avestroxel/creative-web-architect.git
cd creative-web-architect
pnpm install && pnpm build

# Step 2: Initialize target directory
.\cwa.cmd init "C:\Users\YourName\Desktop\my-new-project"

On macOS or Linux, execute the native executable script ./cwa:

# Step 1: Clone & build
git clone https://github.com/Avestroxel/creative-web-architect.git
cd creative-web-architect
pnpm install && pnpm build

# Step 2: Initialize target directory
./cwa init /path/to/my-new-project

If your terminal is already open inside your target folder:

# Initialize inside current working directory
cwa init .

# Or verify system health
cwa doctor

QUESTIONS & ANSWERS

Frequently Asked Questions

Accurate, transparent answers about what Creative Web Architect is and how it functions.

Creative Web Architect is an open-source AI creative engineering toolkit created by Anas Hashim. It equips compatible AI coding environments with autonomous art direction, 36 modular Agent Skills, motion physics, and 39 learned architectural techniques.

Simply clone this repository from GitHub once, build it, and link it via npm link packages/cli. Then in any directory, run cwa init "C:\Path\To\YourProject". It automatically injects all 36 skills, all 39 learned techniques, and the master AGENTS.md / GEMINI.md directives into that folder in seconds.

By default, Creative Web Architect prohibits cheap neon glows, oversaturated gradients, and childish AI aesthetic defaults. Instead, it enforces mature architectural restraint: matte charcoal surfaces, hairline borders, and pure typographic hierarchy.
