ABOUT THE AGENT

An Intelligent Creative Engineering Partner

Creative Web Architect is a modular, open-source agent toolkit designed to equip your existing AI coding environments with authentic design intelligence and production frontend rigor.

ℹ
Toolkit Architecture Notice: Creative Web Architect is not a separate newly trained foundation model. It is an open-source system of 36 Agent Skills, design tokens, kinematic physics, and component engines that connects to compatible AI coding tools (Google Antigravity, Claude Code, Cursor, Gemini CLI) to elevate their web design and implementation capabilities.

GETTING STARTED

Installation & Setup

Get up and running with Creative Web Architect in minutes.

Initialize Creative Web Architect in your current project workspace. The CLI automatically detects your active AI coding tool:

# 1. Initialize CWA configuration
npx @creative-web-architect/cli init

# 2. Install all 36 Agent Skills
npx @creative-web-architect/cli install

# 3. Verify health and environment
npx @creative-web-architect/cli doctor

Clone the repository directly for local development and access to the complete monorepo packages:

# 1. Clone the repository
git clone https://github.com/Avestroxel/creative-web-architect.git
cd creative-web-architect

# 2. Install dependencies across workspaces
pnpm install

# 3. Build core, cli, and effects packages
pnpm build

# 4. Run test suite
pnpm test

Verify that all 36 Agent Skills have valid frontmatter metadata and are registered with your AI environment:

# Run the diagnostic doctor suite
node packages/cli/dist/index.js doctor
