# Cinematic Product Pages

## Purpose

Create Apple-inspired, scroll-driven product showcase pages that combine dramatic visuals with compelling feature storytelling.

## Page Structure

1. **Hero**: Full-screen product on dramatic background, headline, subheadline
2. **Product Reveal**: Scroll-driven zoom, rotation, or camera movement
3. **Feature Sections**: Each key feature gets a dedicated visual section
4. **Specifications**: Technical details in clean grid
5. **Comparison**: Compare models or configurations
6. **CTA**: Purchase or learn-more section

## Techniques

- Pin product in viewport while content scrolls
- Parallax layers create depth
- Text reveals synchronized with product transitions
- Dramatic lighting changes between sections
- Smooth 3D rotation if applicable

## Validation

✅ Story builds naturally through scroll
✅ Key features are highlighted individually
✅ Specifications are clear and scannable
✅ CTA is prominent and compelling
✅ Mobile adaptation preserves impact
