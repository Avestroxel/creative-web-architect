# Nebula.OS — Telemetry & Neural Cluster Operations Dashboard

A production-ready AI telemetry and infrastructure monitoring dashboard generated with **Creative Web Architect**.

## Features

- **Live Streaming Canvas Chart**: Real-time throughput and token bandwidth graphs with multi-series gradients and time filters.
- **Compute Cluster Telemetry**: Granular GPU load, thermal flow metrics, and live status pills with pulse animations.
- **Floating Liquid Glass Dock**: Responsive macOS-style floating dock with magnified hover physics.
- **Quick Command Palette (`Cmd+K` / `Ctrl+K`)**: Keyboard-driven action launcher with fuzzy search and glass backdrop.
- **Live Event Audit Stream**: Monospaced audit logging with real-time incident insertion and severity badges.

## Quick Start

```bash
# Preview locally
pnpm --filter @cwa/template-modern-dashboard dev
# or open index.html directly in any browser
```
