# Kaelen Voss — Creative Technologist Portfolio

A production-ready creative developer & interaction architect portfolio website generated with **Creative Web Architect**.

## Features

- **Dynamic Interactive Cursor & Glow**: Spring-smoothed mouse follower with radial glow halo and micro-scaling hover triggers.
- **Filterable Archive Grid**: Live client-side category filtering (3D & WebGL, Liquid Glass, Generative).
- **Interactive Case Study Modal**: Deep-dive project breakdown with measurable performance metrics, client quotes, and technology tags.
- **Direct Contact Drawer**: Fast copy-to-clipboard contact email with animated feedback.
- **Editorial Typography**: Pairing classical serif headings (`Cinzel`) with modern sans-serif readability (`Plus Jakarta Sans`).

## Quick Start

```bash
# Preview locally
pnpm --filter @cwa/template-creative-portfolio dev
# or open index.html directly in any browser
```
