# Aether Apex — Luxury Electric Grand Tourer Template

A production-ready luxury automotive showcase website generated with **Creative Web Architect**.

## Features

- **Interactive 3D Canvas Wireframe**: Rotatable 3D aerodynamic wireframe using mathematical matrix projections and neon bloom.
- **HUD Live Telemetry**: Dynamic count-up statistics with sub-2 second acceleration metrics and solid-state range.
- **Bespoke Atelier Colorway Switcher**: Interactive paint finish switcher modifying surface reflections, glow highlights, and canvas shaders.
- **Electric Propulsion Sound Engine**: Real-time synthesized hyper-drive acceleration acoustic simulator via Web Audio API.
- **Glassmorphism Design System**: Layered frosted glass panels (`backdrop-filter`), specular borders, and high-contrast typography.
- **Interactive Reservation Modal**: Accessible modal dialog with focus management and allocation priority queue.

## Quick Start

```bash
# Preview locally
pnpm --filter @cwa/template-luxury-automotive dev
# or open index.html directly in any browser
```
