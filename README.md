## Quick Start: Download & Run in Any Folder

### 1. Download & Build (One-Time Setup)
```bash
# Clone repository from GitHub
git clone https://github.com/Avestroxel/creative-web-architect.git
cd creative-web-architect

# Install dependencies and compile packages
pnpm install
pnpm build

# Link CLI globally on your system
npm link packages/cli
```

### 2. Initialize ANY Project Folder in 1 Second
Run `cwa init` pointing to whatever folder you want to build in:

```bash
# Initialize a new or existing project folder anywhere
cwa init "C:\Users\YourName\Desktop\my-new-project"

# Or if your terminal is already inside the project folder:
cwa init .
```

### 3. What Gets Injected Automatically
- **`.agents/skills/` & `skills/`**: All 36 modular Agent Skills ready for Antigravity & AI tools.
- **`knowledge/` & `.agents/knowledge/`**: All 36 learned architectural techniques with master `index.json`.
- **`AGENTS.md` & `GEMINI.md`**: Master directives enforcing the No-Glow policy and anti-generic visual rules.
- **`cwa.config.json`**: Multi-environment auto-detection mapping.

### 4. Build with Your AI Agent
Open your project folder in **Antigravity**, **Cursor**, or **Claude Code**, and prompt your agent:
> *"Build an editorial portfolio in index.html using the learned techniques from knowledge/."*
