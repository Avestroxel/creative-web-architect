# Dashboard Design

## Purpose

Design clear, information-dense dashboard interfaces that present data effectively while maintaining visual quality.

## Layout Patterns

- **Sidebar + Content**: Fixed sidebar navigation with scrollable content area
- **Top Nav + Grid**: Horizontal nav with card-based metric grid
- **Command Center**: Full-screen data visualization with minimal chrome

## Dashboard Components

- Metric cards with trend indicators
- Charts (line, bar, area, donut)
- Data tables with sorting/filtering
- Activity feeds
- Status indicators
- Quick action buttons

## Dark Mode Priority

Dashboards are often viewed for extended periods — dark mode reduces eye strain.
Use subtle surface elevation rather than borders to separate sections.

## Validation

✅ Information hierarchy is clear
✅ Key metrics are immediately visible
✅ Navigation between sections is intuitive
✅ Data density is appropriate (not too sparse, not overwhelming)
✅ Dark mode provides comfortable viewing
