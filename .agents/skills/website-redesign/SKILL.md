# Website Redesign

## Purpose

Systematically analyze and improve existing websites. Preserve required functionality while upgrading design quality, performance, and accessibility.

## Workflow

1. **Audit**: Document current state — design, performance, accessibility, code quality
2. **Identify**: List specific issues with severity (critical, major, minor)
3. **Preserve**: Catalog functionality that must not break
4. **Plan**: Propose improvements in priority order
5. **Implement**: Make changes incrementally, testing after each
6. **Verify**: Confirm improvements without regressions

## Guidelines

- Never destroy existing functionality without approval
- Make incremental changes, not total rewrites
- Preserve existing content and URLs
- Test after each change
- Document before/after differences

## Validation

✅ Existing functionality preserved
✅ Visual improvements measurable
✅ Performance same or better
✅ Accessibility same or better
✅ No broken links or features
