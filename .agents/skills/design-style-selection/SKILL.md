# Design Style Selection

## Purpose

Provide a comprehensive knowledge base of design styles and intelligent selection logic. Match the right visual language to each project based on category, audience, and brand personality.

## Style Categories

### 1. Minimal & Structured

Clean, ordered designs with intentional negative space and geometric precision.

| Style | Best For | Key Techniques |
|---|---|---|
| **Swiss International** | Corporate, finance, institutional | Grid systems, Helvetica, mathematical ratios, restrained color |
| **Contemporary Minimalism** | Tech, SaaS, professional services | Generous whitespace, system fonts, micro-interactions |
| **Japanese Minimalism** | Wellness, luxury goods, art | Wabi-sabi textures, asymmetric balance, organic tones |
| **Scandinavian Design** | Lifestyle, furniture, home | Warm whites, natural materials, soft rounded forms |
| **Editorial Minimalism** | Magazines, blogs, content sites | Strong type hierarchy, reading-first layout, serif headlines |
| **Architectural Minimalism** | Architecture, real estate, space | Monumental scale, structural grids, dramatic photography |
| **Monochrome Design** | Photography, art, premium brands | Single hue or grayscale, high contrast, dramatic shadows |
| **Geometric Modernism** | Creative agencies, education, arts | Bold shapes, primary colors, Bauhaus influence |

### 2. Expressive & Experimental

Bold designs that challenge conventions and prioritize creative expression.

| Style | Best For | Key Techniques |
|---|---|---|
| **Neo-Brutalism** | Creative agencies, startups, tech | Thick borders, bold fills, visible structure, hand-drawn elements |
| **Digital Brutalism** | Developer tools, tech art, hacker culture | Monospace type, raw HTML aesthetic, terminal colors |
| **Maximalism** | Fashion, entertainment, events | Layered patterns, clashing colors, sensory abundance |
| **Experimental Editorial** | Art magazines, cultural institutions | Mixed media, broken grids, dynamic typography |
| **Anti-Design** | Art galleries, underground culture | Deliberate ugliness, confrontational layout, broken rules |
| **Memphis Design** | Youth brands, playful products | Geometric patterns, pastels + neons, 80s boldness |
| **Expressive Typography** | Creative portfolios, type foundries | Typography as primary art, kinetic text, scale play |
| **Generative Design** | Tech art, data visualization, creative coding | Algorithm-driven visuals, procedural patterns, code art |
| **Interactive Art Direction** | Experimental portfolios, installations | Cursor-driven visuals, participatory design |

### 3. Premium & Cinematic

Luxurious, story-driven designs with cinematic pacing.

| Style | Best For | Key Techniques |
|---|---|---|
| **Luxury Editorial** | High-end brands, fashion, jewelry | Premium serif type, generous spacing, editorial photography |
| **Cinematic Product** | Consumer electronics, automotive | Full-screen reveals, dramatic lighting, scroll storytelling |
| **Dark Luxury** | Premium spirits, watches, automotive | Deep dark surfaces, metallic accents, dramatic light |
| **Fashion Editorial** | Fashion brands, designers, models | High-fashion photography, editorial grids, runway aesthetic |
| **Art Deco** | Hotels, spirits, premium events | Geometric ornament, metallic finishes, 1920s glamour |
| **Minimal Luxury** | Premium services, boutique brands | Ultra-refined minimalism, subtle details, quiet confidence |
| **Automotive Showcase** | Car brands, motorsport, mobility | Dynamic vehicle photography, specs, configurators |
| **Premium Product Storytelling** | Any premium product | Scroll-driven narrative, detail close-ups, feature reveals |

### 4. Futuristic & Technological

Forward-looking designs inspired by technology and science fiction.

| Style | Best For | Key Techniques |
|---|---|---|
| **Spatial UI** | VR/AR platforms, 3D tools | Depth layers, floating elements, spatial navigation |
| **Futuristic Interfaces** | AI companies, space tech, defense | HUD elements, data viz, scan-line effects |
| **Cyberpunk** | Gaming, security, crypto | Neon on dark, glitch effects, digital noise |
| **Retro Futurism** | Music, vintage tech, nostalgia brands | Chrome effects, analog-digital blend, optimistic future |
| **Y2K** | Gen-Z brands, pop culture | Chrome text, translucent plastic, cyber-optimism |
| **Glassmorphism** | Dashboards, apps, modern UI | Frosted glass, backdrop blur, subtle borders |
| **Liquid Glass** | Premium apps, next-gen UI | Fluid surfaces, optical depth, dynamic refraction |
| **Generative Shader** | Creative tech, art installations | GLSL visuals, procedural textures, GPU art |

### 5. Organic & Human

Warm, approachable designs inspired by nature and craft.

| Style | Best For | Key Techniques |
|---|---|---|
| **Organic Modernism** | Health, wellness, organic products | Curved forms, biomorphic shapes, flowing composition |
| **Nature-Inspired** | Environmental, outdoor, gardening | Earth tones, botanical elements, natural textures |
| **Warm Editorial** | Personal blogs, storytelling, memoir | Serif type, warm palettes, intimate photography |
| **Handcrafted Design** | Artisan brands, bakeries, crafts | Hand-drawn elements, custom illustration, personal touch |
| **Playful Illustration** | Children, education, casual games | Character art, animated illustrations, vibrant colors |
| **Soft Geometric** | Apps, friendly products, services | Rounded shapes, pastel gradients, gentle precision |
| **Tactile Interfaces** | Touch-first apps, interactive tools | Physical feedback, material depth, satisfying clicks |

## Selection Algorithm

### Step 1 — Category Mapping
Identify the website category and find its natural style affinity:

```
Automotive → Premium Cinematic (automotive-showcase, cinematic-product)
Portfolio → Varies by discipline (minimal, editorial, experimental)
Coffee/Food → Organic Human (warm-editorial, handcrafted)
Tech/SaaS → Minimal Structured (contemporary-minimalism) or Futuristic
Dashboard → Futuristic Tech (glassmorphism, spatial-ui)
Fashion → Premium Cinematic (fashion-editorial, dark-luxury)
Agency → Expressive (neo-brutalism, experimental-editorial)
```

### Step 2 — Personality Modifier
Adjust based on brand personality words:

```
"luxury" / "premium" / "exclusive" → Shift toward Premium Cinematic
"playful" / "fun" / "friendly" → Shift toward Organic Human
"bold" / "edgy" / "disruptive" → Shift toward Expressive Experimental
"clean" / "simple" / "professional" → Shift toward Minimal Structured
"futuristic" / "innovative" / "tech" → Shift toward Futuristic Tech
```

### Step 3 — Style Combination
Allow meaningful style combinations:

```
Japanese Minimalism + Dark Luxury = Zen luxury
Neo-Brutalism + Liquid Glass = Playful transparency
Editorial Minimalism + Kinetic Typography = Dynamic storytelling
Scandinavian + Soft Geometric = Cozy modern
Cyberpunk + Generative Shader = Immersive tech art
```

### Step 4 — Validate Selection
Confirm the selection against:
- ✅ Audience appropriateness
- ✅ Content compatibility (does the style work with the content type?)
- ✅ Technical feasibility
- ✅ Performance budget
- ✅ Accessibility requirements

## Guidelines

- **Never force a style** — if the user's requirements don't fit any predefined style well, create an original combination
- **Styles are starting points** — adapt and customize rather than applying rigidly
- **Consider the competition** — look different from typical sites in the same category
- **Match the content** — text-heavy sites need different styles than image-heavy sites

## Validation

✅ Selected style(s) match the brand personality
✅ Style is appropriate for the target audience
✅ Technical requirements of the style are feasible
✅ Style combination is harmonious (not contradictory)
✅ Selection rationale is documented
