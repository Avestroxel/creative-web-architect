# Portfolio Design

## Purpose

Create distinctive portfolio websites that showcase work effectively while expressing the creator's personality.

## Portfolio Types

| Type | Focus | Style Tendency |
|---|---|---|
| **Developer** | Code projects, technical skills | Minimal, monochrome, technical |
| **Designer** | Visual work, case studies | Editorial, experimental, bold |
| **Photographer** | Image galleries, series | Minimal, full-bleed images |
| **Architect** | Buildings, spatial design | Architectural minimalism, dramatic |
| **Artist** | Artwork, exhibitions | Gallery-like, white space, clean |

## Essential Sections

1. **Hero**: Name, role, one-line positioning
2. **Selected Work**: 4-8 best projects with thumbnails
3. **About**: Brief bio, philosophy, photo
4. **Skills/Services**: Capabilities overview
5. **Contact**: Email, social links, optional form

## Project Showcase Patterns

- **Grid gallery**: Thumbnails that expand to full case study
- **Horizontal scroll**: Projects as a horizontal sequence
- **Full-page**: Each project gets a full-viewport section
- **Case study**: Detailed narrative with process and results

## Validation

✅ Work is the hero, not the UI
✅ Projects are easy to browse
✅ Navigation is minimal but clear
✅ Contact information is accessible
✅ Design reflects the creator's aesthetic
